# 用户交互层设计

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| 实时可见 | 所有 AI 处理过程对用户透明，可实时查看执行状态 |
| 实时可控 | 用户可随时通过指令队列干预 AI 执行 |
| 可提问 | AI 可主动向用户提问，用户回答后自动修正 |
| 可迭代 | 支持选中任意内容进行局部修改 |
| 结构化展示 | PRD、流程图、原型通过结构树关联展示 |

- @ 引用：引用结构树中的节点（@订单列表页面）
- / 命令：快捷指令（/生成PRD、/优化、/评审）
- 消息关联：每条消息关联到 DSL 中的修改

**子视图切换**：

| 标签页 | 内容 | 编辑器/渲染器 |
|--------|------|--------------|
| PRD 文档 | 结构化需求文档 | TipTap 富文本编辑器 |
| 流程图 | 业务流程/审批流程 | AntV X6 图编辑器 |
| 原型 | 页面结构与组件 | HTML 预览 + 标注 |
| 数据模型 | ER 图/实体关系 | AntV X6 图渲染 |

**交互行为**：
- 选中 PRD 文本 → 浮动工具栏（AI 修改/AI 优化/删除/标注）
- 点击流程节点 → 显示节点详情，支持编辑
- 双击原型组件 → 进入编辑模式
- 版本对比 → 左右分栏显示差异（diff 视图）

## 3. 核心交互流程

### 3.1 新需求生成交互流程

```
用户                          系统                          AI Agent
 │                             │                              │
 │── 输入需求/上传文档 ────────▶│                              │
 │                             │── 解析输入 ─────────────────▶│
 │                             │                              │
 │◀── 实时显示(SSE) ──────────│◀── 流式返回需求摘要 ─────────│
 │                             │                              │
 │                             │                              │── 发现不明确点
 │◀── 展示提问卡片 ───────────│◀── 发送澄清问题 ────────────│
 │                             │                              │
 │── 回答问题 ────────────────▶│── 转发答案 ─────────────────▶│
 │                             │                              │
 │                             │                              │── 继续分析
 │◀── 实时更新结构树 ─────────│◀── 返回功能模块 ─────────────│
 │◀── 实时更新产物区 ─────────│◀── 返回 PRD ─────────────────│
 │◀── 实时更新流程图 ─────────│◀── 返回流程 ─────────────────│
 │                             │                              │
 │── 选中内容发出修改指令 ────▶│── 指令入队 ─────────────────▶│
 │◀── 更新指令队列状态 ───────│                              │
 │◀── 局部更新产物 ───────────│◀── 返回修改结果 ─────────────│
 │                             │                              │
```

### 6.2 SSE 实时推送机制

```typescript
// composables/useSSE.ts
interface SSEEvent {
  type: 'stream' | 'question' | 'status' | 'update' | 'error';
  payload: any;
}

// 事件类型说明
// stream   - AI 流式输出文字
// question - AI 提出澄清问题
// status   - 执行状态变更
// update   - DSL / 产物更新
// error    - 错误通知
```

### 6.3 指令队列前端实现

```typescript
// composables/useCommandQueue.ts
interface Command {
  id: string;
  type: 'modify' | 'add' | 'delete' | 'recompute' | 'clarify';
  target: string;           // DSL 路径
  instruction: string;      // 用户指令
  priority: 'high' | 'normal' | 'low';
  status: 'pending' | 'running' | 'done' | 'failed';
  createdAt: string;
  updatedAt: string;
}
```
